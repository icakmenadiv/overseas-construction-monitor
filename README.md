# 해외 건설시장 모니터링

GitHub Pages에서 배포하는 해외 건설·인프라 시장뉴스 및 프로젝트 모니터링 대시보드입니다. 운영 Google Sheets의 핵심 데이터 탭을 정적 JSON 캐시로 동기화해 시장 모니터링, 프로젝트 목록, 프로젝트 상세 화면에서 사용합니다.

## 주요 기능

- 시장 뉴스 목록 조회 및 필터링
- 프로젝트 목록 조회 및 상세 페이지 연결
- 결과 탭 기사와 프로젝트 탭 기준 프로젝트 정보의 정적 캐시 동기화
- 키워드, 날짜 범위, 지역, 국가, 섹터, 정보 분류, 단계별 필터링
- CSV 내보내기 및 원문 링크 이동

## 운영 스프레드시트 연결 원칙

GitHub Pages와 캐시 동기화 워크플로가 운영 스프레드시트에서 직접 읽는 탭은 아래 2개로 제한합니다.

| 용도 | 탭 | gid | 캐시 파일 | 기본 범위 |
| --- | --- | --- | --- | --- |
| 기사/시장 모니터링 | `결과` | `748239675` | `data/articles.json` | `A1:Z50000` |
| 프로젝트 모니터링 | `프로젝트` | `20260612` | `data/projects.json` | `A1:M20000` |

`Search_Log`, `관심도_집계`, `조회수_집계`, `중요도_학습모드`, 숨김 정비 탭 등 운영 보조 탭은 GitHub Pages 데이터 캐시의 소스 탭으로 사용하지 않습니다. 관심도나 조회수처럼 별도 집계가 필요한 기능은 각각의 전용 API, 캐시 파일, 또는 Apps Script 흐름에서 분리해 다룹니다.

## 파일 구성

- `index.html`: 시장 모니터링 화면 구조
- `app.js`: 시장 모니터링 데이터 로딩, 필터, 정렬, 상세 보기 로직
- `projects.html`: 프로젝트 목록 화면 구조
- `projects.js`: 프로젝트 목록 데이터 로딩, 필터, 정렬, 관련 기사 연결 로직
- `project.html`: 프로젝트 상세 화면 구조
- `project.js`: 프로젝트 상세 및 관련 기사 표시 로직
- `scripts/sync-sheet-cache.mjs`: 운영 스프레드시트의 `결과`, `프로젝트` 탭을 정적 JSON 캐시로 동기화
- `sheet-cost-optimizer.js`: Google Sheets 직접 조회 요청을 정적 캐시로 우선 대체하는 브라우저 보조 로더
- `data/articles.json`: `결과` 탭 기반 기사 캐시
- `data/projects.json`: `프로젝트` 탭 기반 프로젝트 캐시
- `data/meta.json`: 캐시 동기화 기준, 건수, 변경 내역 메타데이터

## 캐시 동기화

GitHub Actions의 `Sync sheet cache` 워크플로가 `scripts/sync-sheet-cache.mjs`를 실행해 운영 스프레드시트의 `결과`와 `프로젝트` 탭만 읽습니다.

```bash
node scripts/sync-sheet-cache.mjs --mode=reconcile
```

동기화 스크립트에는 허용된 소스 탭 목록이 명시되어 있어, 다른 운영 보조 탭의 gid나 범위가 실수로 들어오면 실행을 중단합니다.

## Google Sheets 공개 설정

1. 운영 Google Sheets에서 `공유`를 클릭합니다.
2. GitHub Pages에서 직접 fallback 조회가 필요하면 링크가 있는 사용자가 볼 수 있도록 권한을 설정합니다.
3. 공개 범위가 제한되어 있으면 정적 캐시는 유지되더라도 브라우저 fallback 조회가 실패할 수 있습니다.

## 데이터 컬럼명

`결과` 탭은 기사 고유값, 프로젝트 고유값, 정보 분류, 중요도, 중요도 수치값, 출처링크 등 운영 스키마의 핵심 열을 유지해야 합니다.

`프로젝트` 탭은 프로젝트 고유값, 프로젝트명, 지역, 국가, 섹터, 발주처, 사업비, 현재 단계, 최근 업데이트일, 대표 기사 고유값 등 프로젝트 모니터링 기준 열을 유지해야 합니다.

## GitHub Pages 배포

1. 저장소의 `main` 브랜치가 GitHub Pages 배포 소스입니다.
2. 캐시 동기화 워크플로가 `data/articles.json`, `data/projects.json`, `data/meta.json`을 갱신하면 페이지가 최신 운영시트 내용을 읽습니다.
3. 브라우저에서 캐시가 비어 있거나 실패할 때만 Google Sheets 원본 탭을 fallback으로 조회합니다.
